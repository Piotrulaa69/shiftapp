EKRAN 1 Dashboard (Home)
EKRAN
Karta: najbliższa zmiana (data, godziny, lokalizacja) + Przycisk Clock-in/out
Karta: zarobki bieżącego okresu (łączna kwota) → EKRAN 1B
Karta: punkty bieżącego okresu (łączna liczba + pozycja w rankingu) → zakładka Szkolenia
EKRAN 1A Clock-in
Przyjście przed zmianą → naliczanie od godziny z grafiku. Spóźnienie → od faktycznej godziny. Clock-in na czas → punkty za punktualność.
1A-PIN — Weryfikacja PINem
Pole na PIN (4–6 cyfr)
Przycisk: „Potwierdź"
Błędny PIN → komunikat błędu + możliwość ponowienia
Poprawny PIN → status: TRWA → powrót do Home
1A-QR — Weryfikacja kodem QR
Uruchomienie kamery urządzenia
Skanowanie QR wyświetlanego w miejscu pracy (unikalny per zmiana)
Błędny / nieaktualny kod → komunikat błędu
Poprawny kod → status: TRWA → powrót do Home
1A-GPS — Weryfikacja lokalizacją
Aplikacja pobiera lokalizację urządzenia
Porównanie z adresem i radiusem GPS lokalizacji (konfigurowalne)
Za daleko → komunikat z informacją o odległości
W zasięgu → status: TRWA → powrót do Home
1A-OUT — Spóźniony clock-out
Wyzwalacz: brak clock-out po zakończeniu zmiany → push do pracownika.
Opcja A — Skończyłem: pole godziny wyjścia → „Zapisz" → clock-out wsteczny
Opcja B — Nadal pracuję: pole tekstowe (wymagane: 1 zdanie) → „Zapisz" → alert do managera
Brak reakcji: auto clock-out o godzinie końca zmiany z grafiku
EKRAN 1B Zarobki
Nazwa okresu rozliczeniowego (okres definiowany przez pracodawcę)
Łączna kwota do wypłaty za okres
Jeśli pracownik pracował na kilku stanowiskach → podział per stanowisko (np. Kierowca: 800 zł / Kelner: 400 zł)
Jeśli nadgodziny → podział: regularne + nadgodziny z osobnymi kwotami
Status: W TRAKCIE / ZAMKNIĘTY
Nawigacja ← → między okresami (pełna historia, bez limitu) — tylko podgląd
EKRAN 2 Grafik
EKRAN
Kalendarz / lista zmian: poprzednie → aktualny → przyszły (jeśli opublikowany)
Status zmian: NADCHODZĄCA TRWA ZAKOŃCZONA
Przyciski na dole: „Dyspozycyjność" → EKRAN 2B | „Wnioski urlopowe" → EKRAN 2C
EKRAN 2A Szczegóły zmiany
Data, godziny, lokalizacja, stanowisko
Faktyczny clock-in / clock-out (jeśli zakończona)
Notatka od managera (jeśli istnieje)
Przycisk: „Zgłoś nieobecność" (tylko dla zmian NADCHODZĄCA) → EKRAN ABS-1
Przycisk: „Zaproponuj wymianę" → EKRAN SWAP-1
EKRAN 2B Dyspozycyjność
Kalendarz miesięczny, nawigacja w przód bez limitu
Domyślny stan: full-time → DOSTĘPNY / part-time → NIEDOSTĘPNY
Dni z przypisaną zmianą w grafiku → zablokowane
Przycisk „Zapisz" → zapisuje cały miesiąc → powrót do Grafiku
2B-1 — Ustawienie dnia (bottom sheet)
Opcja A — Dostępny cały dzień: DOSTĘPNY → zamknięcie
Opcja B — Niedostępny: NIEDOSTĘPNY → zamknięcie
Opcja C — Częściowo: sheet rozszerza się o 2 przedziały: Od–Do (przedział 1 wymagany, 2 opcjonalny)
Walidacja: „Do" późniejsze niż „Od", przedziały nie mogą się nakładać
EKRAN 2C Wnioski urlopowe
Saldo dni urlopowych (per typ skonfigurowany przez pracodawcę)
Lista wniosków z filtrami: wszystkie / oczekujące / zatwierdzone / odrzucone
Przycisk: „Nowy wniosek" → EKRAN 2C-1
2C-1 — Nowy wniosek (formularz 2-krokowy)
Krok 1: wybór typu urlopu (lista typów z pracodawcy)
Krok 2: data od + data do + automatyczne wyliczenie dni roboczych
Walidacja: brak salda → blokada | kolizja z zatwierdzonym wnioskiem → błąd
Pola dodatkowe zależne od typu: komentarz (opcjonalne / wymagane) + załącznik
Wyślij → status: OCZEKUJĄCY → push do pracownika
2C-2 — Szczegóły wniosku
Typ, daty, dni, data złożenia, status, komentarze, załącznik
Status OCZEKUJĄCY → przycisk „Anuluj wniosek" → dialog → ANULOWANY
Pozostałe statusy → tylko podgląd
EKRAN ABS-1 Zgłoś nieobecność nieplanowaną
Typ: L4 / Opieka nad dzieckiem / Siła wyższa / Inne
Opis (wymagane dla „Inne"), załącznik (opcjonalne)
Wyślij → status zmiany: NIEOBECNOŚĆ ZGŁOSZONA → push do managera
EKRAN SWAP-1/2 Wymiana zmian (pracownik)
SWAP-1 (inicjator): wybór pracownika z tym samym stanowiskiem → „Wymień za zmianę" lub „Oddaj zmianę" → wyślij do pracownika B
SWAP-2 (odpowiedź): podgląd propozycji → „Zaakceptuj" (→ do managera) lub „Odrzuć" (→ push do A)
EKRAN 3 Zadania
EKRAN
Lista zadań pracownika i jego roli / stanowiska
Typy: Cykliczne (auto) | Przypisane do zmiany | Przypisane imiennie
Per zadanie: nazwa, opis, termin, punkty za wykonanie, status DO ZROBIENIA / ZROBIONE
EKRAN 3A — Szczegóły zadania
Punkty dodawane dopiero po zatwierdzeniu przez managera, nie od razu po oznaczeniu.
Pole tekstowe: komentarz (opcjonalne)
Przycisk: dodaj zdjęcie jako dowód wykonania
Przycisk: „Oznacz jako wykonane" → CZEKA NA ZATWIERDZENIE → push do managera
Po odrzuceniu: komentarz managera + info o której zmianie zadanie pojawi się ponownie
EKRAN 4 Szkolenia + System punktów
EKRAN
Sekcja „Moje punkty"
Łączna liczba punktów w bieżącym okresie rozliczeniowym
Pozycja w rankingu zespołu (np. „3 / 12")
Ranking zespołu: imię nazwisko + punkty per osoba
Historia zdarzeń: data, zdarzenie, punkty
Nawigacja ← → między poprzednimi okresami
Sekcja „Szkolenia"
Lista: nazwa, typ, punkty, status NOWE W TRAKCIE UKOŃCZONE
Filtr: wszystkie / do zrobienia / ukończone
4A — Materiał (PDF / wideo)
PDF viewer lub odtwarzacz wideo, pasek postępu
Przycisk: „Potwierdzam zapoznanie" → UKOŃCZONE → punkty dodane
4B — Test / Quiz
Pytania (jednokrotny / wielokrotny wybór)
Wynik wyświetlony od razu → punkty proporcjonalne do wyniku (im lepszy % tym więcej punktów)
Wynik widoczny dla managera
4C — Materiał + Test
Najpierw 4A → punkty za materiał
Po potwierdzeniu → odblokowanie 4B → dodatkowe punkty za wynik testu
EKRAN 5 Profil pracownika (top bar → avatar)
EKRAN
Moje dane (podgląd): imię, nazwisko, stanowiska, firma, typ zatrudnienia
Edytowalne: zdjęcie, telefon, e-mail (potwierdzenie), hasło → EKRAN 5A
Powiadomienia: per typ: Push / E-mail / Push+E-mail / Wyłączone
Dokumenty: lista dokumentów pracownika → EKRAN DOC-1
Inne: Wyloguj (dialog) | wersja aplikacji
5A — Zmiana hasła
Pole: aktualne hasło
Pola: nowe hasło + powtórz (min. 8 znaków, identyczne)
Przycisk „Zapisz" → potwierdzenie → powrót do profilu
DOC-1/2/3 — Dokumenty
DOC-1 Lista: filtr statusu, typy: UMOWA / ZAŚWIADCZENIE / CERTYFIKAT / INNE, badge wygaśnięcia
DOC-2 Dodaj: nazwa, typ, data wygaśnięcia (opcjonalna), upload PDF/JPG/PNG
DOC-3 Szczegóły: podgląd pliku, pobierz, edytuj metadane, usuń (dialog)
Przypomnienia: 30 dni i 7 dni przed wygaśnięciem → push + e-mail
Widoczność: pracownik + jego manager + pracodawca
EKRAN CHAT Czat (top bar → ikona)
EKRAN
Czat 1:1 — pracownik ↔ manager. Brak czatu grupowego w MVP. Pracodawca nie ma czatu.
CHAT-1 — Lista konwersacji
Avatar, imię, ostatnia wiadomość, czas, badge nieprzeczytanych
Wyszukiwarka po imieniu
Pracownik widzi tylko managerów | Manager widzi cały zespół
CHAT-2 — Rozmowa
Wiadomości bąbelkowe z datą/godziną
Pole tekstowe + wyślij + dodaj zdjęcie (galeria / aparat)
Wiadomości oznaczane jako przeczytane po otwarciu
Widok managera
Nawigacja: Home / Grafik / Zespół / Więcej | Przełącznik: Mój widok / Zespół
MANAGER Przełącznik top bar: Mój widok (= widok pracownika) / Zespół
EKRAN M1 Dashboard managera
EKRAN
Sekcja „Dziś"
Lista zmian na dziś: imię, godziny, status: NA CZAS SPÓŹNIENIE BRAK CLOCK-IN NADAL PRACUJE
Kliknięcie pracownika → EKRAN M1A
Sekcja „Do zatwierdzenia" (liczniki per kategoria)
Wnioski urlopowe → EKRAN M3C
Clock-outy wsteczne → EKRAN M1B
Zadania do zatwierdzenia → EKRAN M4A
Wymiany zmian → EKRAN SWAP-3
Nieobecności → EKRAN ABS (manager)
M1A — Szczegóły obecności + M1A-1 Korekta godzin
Imię, rola, zaplanowane i faktyczne godziny, metoda weryfikacji, notatka clock-out
Historia obecności ostatnich 7 dni
Przycisk „Ręczna korekta" → pola godziny in/out + powód korekty (wymagany) → zapisz
M1B — Clock-outy wsteczne do weryfikacji
Lista: imię, data zmiany, godzina z grafiku, godzina podana przez pracownika, notatka
Bottom sheet: „Zatwierdź" / „Koryguj godzinę" / „Odrzuć" (→ auto clock-out z grafiku)
Każda akcja → push do pracownika
M-QR — Kody zmian (QR / PIN)
Kody generowane automatycznie per zmiana przy publikacji grafiku. Unikalny kod per zmiana.
Lista zmian na dziś: pracownik, godziny, PIN lub przycisk „Pokaż QR"
Pełnoekranowy QR do pokazania pracownikowi lub wydruku
Przycisk „Odśwież kod" → generuje nowy (gdy kod wyciekł)
Kod ważny: od X minut przed zmianą do końca zmiany (X konfigurowalne)
EKRAN M2 Grafik — tworzenie i zarządzanie
EKRAN
Podzakładki: Bieżące / Archiwum
Lista grafików: SZKIC / OPUBLIKOWANY
Przycisk „Nowy grafik" → EKRAN M2A | Kliknięcie grafiku → EKRAN M2B (edytor)
M2A — Nowy grafik (inicjalizacja)
Pole: okres rozliczeniowy (auto-wybrany następny nieobsadzony)
Pole: lokalizacja (jeśli manager zarządza kilkoma)
Przycisk „Generuj propozycję" → system analizuje dyspozycyjność + urlopy + typ zatrudnienia → otwiera M2B ze szkicem
M2B — Edytor grafiku (siatka)
Siatka: kolumny = dni okresu, wiersze = pracownicy
Kolory komórek: zmiana (wg roli) | urlop (zielony, zablokowany) | niedostępny (szary, ostrzeżenie) | KONFLIKT (czerwony)
Pusta komórka → bottom sheet Dodaj (M2B-1) | Zajęta → Edytuj / Usuń / Przenieś
Toolbar: „Kopiuj okres" | „Zapisz szkic" | „Publikuj" → push do pracowników
M2B-1 — Dodaj zmianę (bottom sheet)
Godzina od / do (time picker)
Stanowisko (wymagane jeśli pracownik ma kilka) → stawka naliczana automatycznie
Notatka dla pracownika (max 200 znaków, opcjonalne)
Ostrzeżenie jeśli: poza dyspozycyjnością | przekroczenie limitu godzin (można zignorować)
M2B-2 — Edytuj zmianę (bottom sheet)
Pola godzin + stanowisko + notatka (preuzupełnione)
Edycja opublikowanego grafiku → push do pracownika „Zmiana w grafiku"
M2 Archiwum — Grafiki historyczne
Lista zamkniętych okresów, nawigacja bez limitu wstecz
Podgląd siatki (tylko do odczytu)
Przycisk „Kopiuj jako nowy szkic" → otwiera M2B z skopiowanym grafikiem
Eksport: PDF / CSV
EKRAN M3 Zespół
EKRAN
Lista pracowników z filtrem aktywni/archiwalni i wyszukiwarką
Badge przy pracowniku: liczba wygasających dokumentów
Długie przytrzymanie → multi-select → akcje zbiorcze: przypisz zadanie / szkolenie / wyślij wiadomość
Przycisk „Dodaj pracownika" → M3A (zaproszenie e-mail)
M3B — Profil pracownika (manager)
Dane podstawowe: podgląd
Ustawienia zatrudnienia: lista stanowisk z osobną stawką per stanowisko, typ zatrudnienia, limit godzin (tygodniowy / miesięczny), dni urlopu, lokalizacje, metoda clock-in
Dyspozycyjność: zbiorcza siatka miesięczna (podgląd)
Dokumenty: → EKRAN DOC-1
Historia: godziny / wnioski / punkty per okres
Archiwizuj / Przywróć pracownika (dialog)
M3C — Wnioski urlopowe do zatwierdzenia
Przy zatwierdzeniu — system sprawdza kolizję ze zmianami w grafiku → dialog: usuń zmiany lub zostaw z oznaczeniem KONFLIKT.
Lista oczekujących z filtrem (osoba / typ)
Bottom sheet: podgląd + saldo dni + ostrzeżenie o nakładaniu się urlopów w zespole
Zatwierdź → ZATWIERDZONY → dni odjęte z salda → push | Odrzuć → powód wymagany → push
SWAP-3 — Zatwierdzenie wymiany zmian
Podgląd wymiany: pracownik A ↔ pracownik B, obie zmiany
Ostrzeżenie jeśli wymiana powoduje przekroczenie limitu godzin
Zatwierdź → grafik zaktualizowany → push do obu | Odrzuć → powód → push do obu
EKRAN M4 Więcej (kafelki)
EKRAN
M4A — Zadania
Podzakładki: Do zatwierdzenia / Aktywne / Archiwum
Multi-select na liście „Do zatwierdzenia": masowe zatwierdzenie / odrzucenie z jednym powodem
Formularz nowego zadania: nazwa, opis, punkty, termin, przypisz do (osoba / rola / zmiana), cykliczne (tak/nie → cykl)
Zatwierdzenie zadania: podgląd zdjęcia dowodu + komentarz → Zatwierdź (→ punkty) / Odrzuć (→ zadanie wraca na zmianę)

Podzakładki: Biblioteka / Przypisane / Wyniki

Obecność/godziny: zaplanowane vs. przepracowane, nadgodziny, spóźnienia, limit godzin vs. faktyczne
Zarobki zespołu: stawka, godziny, kwota per pracownik, suma łączna
Punkty i rankingi: pozycja, łączne punkty, podział kategorii, trend vs. poprzedni okres
Realizacja zadań: przypisane vs. wykonane vs. zatwierdzone, zaległe, procent per rola
Każdy raport: Eksport PDF / CSV

P6–P9 Konfiguracja firm
KONFIGURACJA
Każda firma ma własne, niezależne ustawienia. Globalny szablon + nadpisanie per firma.
P6A — Konfiguracja firmy
Czas pracy: metoda clock-in (PIN/QR/GPS), okno clock-in (minuty przed zmianą), próg spóźnienia wymagający komentarza
Okresy rozliczeniowe: tygodniowy / dwutygodniowy / miesięczny / własny (dni), data startowa
Wynagrodzenia: model (godzinowy/miesięczny/mieszany), nadgodziny (próg dzienny + tygodniowy + mnożnik), czas poprawy zadania = odejmowany od czasu pracy (toggle)
Urlopy: lista typów (dodaj/edytuj/usuń) → per typ: nazwa, dni w roku, wymagany załącznik, wymagany komentarz
Dyspozycyjność: termin składania (X dni przed) + domyślny stan bez dyspozycyjności (dostępny/niedostępny)
P7 — Modele wynagrodzeń
Formularz: nazwa, typ (godzinowy/miesięczny), stawka bazowa
Dodatki: nocna / weekendowa / świąteczna (mnożnik per typ)
Modele przypisywane do pracowników w profilu (per stanowisko)
P8 — System punktów
Wartości per zdarzenie: clock-in na czas | zadanie | szkolenie | wynik testu (przelicznik %→pkt)
Nagrody: próg punktowy → opis nagrody (dodaj/usuń progi)
Opis dla pracowników: pole tekstowe wyświetlane w aplikacji
Reset: automatyczny co okres rozliczeniowy (informacja, nie konfigurowalne)
P9 — Role i stanowiska
Lista ról per firma (np. kucharz, kelner, kierowca, pizza master)
Usunięcie roli: możliwe tylko jeśli brak aktywnych pracowników z tą rolą jako jedynym stanowiskiem
Role używane przy: zadaniach, szkoleniach, raportach, dyspozycyjności
Uzupełnienia globalne
Logika przekrojowa dotycząca wielu ekranów
Wielostanowiskowość — zmiany w wielu ekranach
ZMIANA
Profil pracownika (M3B/P11B): lista stanowisk zamiast jednego pola, stawka per stanowisko, jedno domyślne
Dodaj zmianę (M2B-1): wybór stanowiska wymagany gdy >1, stawka auto-wypełniana
Zarobki (EKRAN 1B): podział sumy per stanowisko gdy pracował na kilku w okresie
Raporty kosztów (M4C/P2B): dodatkowy filtr per stanowisko
Zadania: przypisanie do roli → trafia do wszystkich pracowników z tym stanowiskiem
Logika zwracania odrzuconych zadań
LOGIKA
Zadanie do zmiany: jeśli zmiana trwa → wraca do tej samej | jeśli zmiana skończyła się → przechodzi na kolejną zmianę
Zadanie do pracownika: zawsze na kolejną zmianę tego pracownika
Konfiguracja pracodawcy: czas poprawy = wliczany do czasu pracy / odejmowany (toggle w P6A)
Pracownik widzi: komentarz managera + info o której zmianie zadanie pojawi się ponownie
Limit godzin per pracownik
KONFIGURACJA
Konfiguracja w profilu pracownika (M3B/P11B): max godzin tygodniowo + max miesięcznie (oba opcjonalne)
Dodawanie zmiany (M2B-1): ostrzeżenie przy przekroczeniu, manager może zignorować
Wymiana zmian (SWAP-3): ostrzeżenie jeśli wymiana powoduje przekroczenie
Raporty: kolumna limit vs. przepracowane, oznaczenie przekroczeń
Urlop a konflikt ze zmianami w grafiku
LOGIKA
Po zatwierdzeniu wniosku: system sprawdza czy są zmiany w dniach urlopu
Dialog: „Usuń zmiany z grafiku" lub „Zostaw — zdecyduję później"
Zostaw → zmiany oznaczone KONFLIKT (czerwone w siatce), manager usuwa ręcznie
Nadgodziny
KONFIGURACJA
Konfiguracja (P6A): próg dzienny (np. po 8h) + tygodniowy (np. po 40h) + mnożnik (np. 1.5x)
Naliczanie: automatyczne po clock-out, spóźnienie nie skraca podstawy (liczymy od grafiku)
Pracownik (1B): podział regularne + nadgodziny z osobnymi kwotami
Manager (M4C): kolumna nadgodziny w raporcie + alert na Home
Pracodawca (P2B): podział kosztów regularne vs. nadgodziny
Zbiorcze akcje na listach
ZMIANA
Wzorzec: długie przytrzymanie → tryb multi-select → checkbox per element → toolbar na dole → „Anuluj" wychodzi z trybu.
Lista pracowników (M3/P11): przypisz zadanie | przypisz szkolenie | wyślij wiadomość | archiwizuj
Lista zadań do zatwierdzenia (M4A): zatwierdź wszystkie zaznaczone | odrzuć z jednym powodem
Wyniki szkoleń (P14): eksportuj zaznaczone PDF/CSV

🔵 Strefy czasowe dla wielu lokalizacji
Odłożono — wymagane gdy aplikacja obsługuje lokalizacje w różnych strefach czasowych (np. różne kraje). Clock-in i grafik muszą działać w lokalnej strefie. Do rozpisania przed implementacją funkcji multi-kraj.
🔵 Zadania cykliczne a urlop pracownika
Odłożono — nierozstrzygnięte: czy zadanie cykliczne przypadające na dzień urlopu jest pomijane, przypisywane innemu pracownikowi z tą samą rolą, czy czeka do powrotu. Do decyzji product ownera.
